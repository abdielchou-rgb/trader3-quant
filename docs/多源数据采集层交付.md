## 三、大模型解读层（interpret.py）— 语义催化

采集到的原始文本不直接入库，先经解读层判断"会不会改变预期"：

```
原始文本 → LLM 语义解读（direction/score/category/affected_codes/reasoning）
         → 无 LLM 时 → 规则评分兜底（催化剂关键词分层）
```

**LLM 判定示例（真实运行）：**
```
贵州茅台董事长：白酒行业深刻调整 → 规则兜底 neutral 0.40（无 LLM key 时）
中标10亿工程项目                  → positive 0.73 订单/合同 ✅
股东拟减持2%                      → negative 0.25 股东/机构 ✅
```

> LLM 接入：配置 `DEEPSEEK_API_KEY`（对齐 2hao .env）即自动启用 LLM 解读，
> 未配置时规则兜底保证流程不中断。

## 四、端到端演示结果（真实运行）

```
自选股: 600519/000858/300750
事件库: 195 条事件（含今日采集）

TRIGGER 000858(五粮液) 催化0.81 估值1.00 技术0.50 信号0.77
  ✅ 催化强 × 低估(+37.5%) → 触发买入
TRIGGER 300750(宁德)    催化0.81 估值1.00 技术0.50 信号0.77
  ✅ 催化强 × 低估(+45.2%) → 触发买入
watch   600519(茅台)    催化0.73 估值0.10 技术0.50 信号0.47
  观察 — 高估(-25.2%) 被估值门槛拦截 ✅（正确拒绝）
```

**验证结论**：
- 事件催化已自动接入三因子引擎（不再手动注入）
- 估值门槛正确拦截高估标的（茅台）
- 三因子门槛避免噪音触发（符合"只在高确信开口"设计）
