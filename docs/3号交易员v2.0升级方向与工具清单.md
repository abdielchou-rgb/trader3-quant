## 二、还能怎么升级（按价值排序）

### P0 — 直接增强现有能力（本周~2周）

1. **可比池自动构建**（comps 当前痛点）
   - 从 financials.db 按行业映射表自动拉同行业股票作可比池，不再靠手工传。
   - 工具：需要一份 A股「行业↔成分股」映射（Tushare Pro 的行业分类 / 申万行业）。
   
2. **每日定时自动化**
   - 盘前采集 → 盘后扫描 → 生成提醒，落到 Windows 定时任务。
   - 工具：本机 `run_local_sources.py` + `daily_pipeline` + Windows 任务计划/Task Scheduler。

3. **提醒通道**
   - 触发时给你推送：桌面通知/邮件/企业微信/钉钉机器人 Webhook。
   - 工具：`notify` 库 / 微信 webhook（免费）。

4. **真实执行桥（QMT）**
   - 从「提醒」到「下单」：对接 QMT 交易接口（券商 miniQMT）。
   - 工具：miniqmt (迅投) / xtquant（QMT 的 Python 接口）——但需券商账户开通，作为独立模式可选。

5. **数据自动更新管线**
   - qlib_bin 增量更新 + financials.db 补充 + 每日事件采集，一体化 cron 脚本。
   - 已有：sync_qlib_data.py（可扩成 `sync_all.py`）。

### P1 — 方法论增强（2~4周）

6. **因子工厂深度对接**
   - evolve/GP 进化出因子 → 接入 `validate_signal` 自动注册新因子。
   - 工具：QLib 的因子表达引擎 + 我们已有的 GP 进化工厂。

7. **行业景气扫描升级**
   - 用高频指标（粗钢/PTA/开工率，来自吸收的宏观方法论）做每日「行业温度计」。
   - 工具：akshare 行业/宏观高频接口（部分可用）。

8. **财报季事件日历**
   - 预知财报/机构调研/解禁/股东大会，触发前 N 天预警。
   - 工具：akshare 业绩预告/解禁/股东大会接口 + events.db。

9. **机构动向增强**
   - 龙虎榜席位画像（著名游资 vs 机构）→ 催化强度加权。
   - 工具：龙虎榜数据已采；需一份「游资席位名册」知识库。

10. **LLM 深度解读（报告级）**
    - 采集文本 → 大模型解读成「催化/方向/受影响标的」结构化信号（当前规则兜底）。
    - 工具：DeepSeek API（已对齐 2hao 的 .env）或本地 VLM。

### P2 — 长周期（1~2月）

11. **组合级再平衡**（从「个股提醒」到「组合管理」）
    - 每日持仓跟踪 + 目标权重 vs 现实 → 再平衡提醒 + 调仓成本(TCA)算总账。
    - 工具：复用 optimize_portfolio + execution cost，加一个 `portfolio_tracker.py`。

12. **回测口径对齐 A股**（涨跌停/T+1/印花税）
    - 当前回测已含印花税；补涨跌停无法成交、T+1 无法日内卖的真实约束。
    - 工具：QLib 的自定义交易成本模块（我们已有基础）。

13. **策略评估报告（进入 2hao 报告）**
    - 把提醒/策略表现沉淀成周报/月报，2hao 可直接引用。
    - 工具：已对接 `trader3_integration` skill。

## 四、下一步建议（三选一启动）

1. **P0-1 可比池自动构建**：Tushare Pro 行业分类 → financials.db 自动生成可比池 → comps 从「数据不足」变「真出结论」，直接可被 2hao 引用。
2. **P0-2 每日定时 + 提醒通道**：让系统真正「每天跑、触发即通知」，形成使用闭环。
3. **P0-3 QMT 执行桥**：把提醒变成可执行订单（需你本机券商环境）。

> 我建议先从 **P0-2（每日定时+提醒）** 起步——它让整个系统「活」起来（每天自动采集+扫描+推送），而不仅仅是停留在工具。你倾向哪个？
