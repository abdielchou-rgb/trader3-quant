# 3号交易员重定位方案 — AI 投研交易日系统

> 定位调整：从「量化回测引擎」→「深度研究驱动的每日交易分析 + 买卖点提醒 + 自选股跟踪」
> 生成日期：2026-08-13

## 一、这个思路怎么样 —— 我的判断

**方向正确，而且是你现有资产的自然延伸。** 但有几个关键认知要先立住。

### 1.1 本质是什么

你描述的其实不是「量化交易系统」，而是 **「基本面/事件驱动的 AI 投研助手 + 决策提醒器」**。它的 alpha 不来自模型预测股价，而来自三件事：

| Alpha 来源 | 机制 |
|-----------|------|
| **信息处理差** | 每天抓取全网公开信息，比大多数人更快、更全面地综合（公告/新闻/研报/互动易/龙虎榜） |
| **预期差识别** | 把 LLM 综合出的「事实全貌」与市场已有定价做对比，找出被低估/高估的预期差 |
| **纪律执行** | 有明确的买卖点规则、跟踪状态机、提醒门槛——避免情绪化交易 |

这不是黑箱预测，是「更努力、更系统、更纪律」地做价值投资。这正好避开你明确不要的高频竞争，落在 AI 真正有相对优势的地方。

### 1.2 为什么在 A 股尤其可行

- **A股散户主导**，信息处理速度差异巨大——你跑得快就是优势
- **政策市+事件驱动**，公告/政策/龙虎榜是主要价格驱动，正是 LLM 信息综合的强项
- **T+1、涨跌停限制**高频，天然适合日频/事件驱动，不需要毫秒级
- 你的 2hao 已有深度研究能力 + 3hao 已有量化验证能力，二者缝合刚好覆盖「研究→信号→验证→提醒」全闭环

### 1.3 必须警惕的四个陷阱

| 陷阱 | 规避 |
|------|------|
| **「每天分析」≠「每天有操作」** | 日报是研究，买卖点提醒才有操作价值。强行每天给操作 = 噪音 |
| **提醒轰炸** | 必须设触发门槛，只有信号强度超过阈值才打扰你 |
| **研究结论 ≠ 交易信号** | 深度研究（2hao）是「对不对」，买卖点触发（3hao）是「何时做」，要分开 |
| **数据合规** | 公告/新闻/公开研报没问题；注意版权和爬取频率控制 |

## 二、网上顶级思考（真实检索结果）

### 2.1 学术证据：LLM 在投研上到底有没有用

这些论文支撑了「LLM 能帮助投资分析」的核心理念：

| 论文 | 核心发现 |
|------|----------|
| **Financial Statement Analysis with LLMs**（芝加哥 Booth, Kim 等） | GPT-4 读标准化匿名财报预测盈余方向，**优于人类分析师**，空头/多头组合可产生交易 alpha |
| **Can ChatGPT Forecast Stock Price Movements?**（Lopez-Lira & Tang） | ChatGPT 对新闻标题的情绪解读有**显著正向预测力**（这是该领域被引用最多的发现之一） |
| **Can LLMs Beat Wall Street?**（arXiv 2401.03737） | LLM 在股票选择/组合配置上展示超越基准的潜力 |
| **ChatGPT-4 with internet: live experiment**（Alpha Architect 引用） | 联网 ChatGPT 的评级与**未来盈余公告和股票收益正相关** |
| **ChatGPT in Systematic Investing**（SSRN 5680782） | LLM 判断「新闻是否支持动量延续」→ 增强动量策略，**夏普/索提诺比率提升**，样本外也有效 |
| **CoT for A-share forecasting**（ScienceDirect 2026） | Chain-of-Thought 在 **608 家 A股公司(2010-2023)** 盈余方向预测上对标人类分析师 |
| **Stock portfolio selection based on risk appetite**（ScienceDirect 2025） | ChatGPT 可按个人风险偏好调整组合风险收益 |

**诚实的注脚**：这些研究多在美股/样本有限，方法学有争议；但它们共同证明一件事——**LLM 在结构化财务数据解读 + 非结构化文本（新闻/公告）解读上有真实价值**，这正是你要做的两个核心功能。

### 2.2 实践方法论：顶级思考

| 思考 | 要点 | 对 3hao 的启示 |
|------|------|----------------|
| **多 Agent 模拟交易公司**（TradingAgents 生态文章） | 不只是情绪分析，多 Agent 架构模拟研究/交易/风控角色，混合 LLM+RL | 你的 2hao(研究)+3hao(量化)+marvis(执行) 天然就是多 Agent 分工 |
| **Agent 平台整合**（FinRobot 架构） | 单一 LLM 不够，要 LLM+RL+量化分析三层整合，自动化投研/策略/风控 | 3hao 重定位后应是「数据采集→研究→验证→提醒」四层而非单工具 |
| **数据为中心**（FinGPT 理念） | 金融 LLM 价值在数据工程（获取/清洗/预处理），模型是其次 | 每天抓取信息的数据管线是第一优先级，比模型选择重要 |
| **事件驱动/催化框架**（业界共识） | 价格在事件附近变动最快，识别催化是日频系统的核心 | 买卖点提醒本质是「催化事件 × 估值分位 × 技术位」三因子触发 |

### 4.1 自选股跟踪状态机（核心创新点）

你提到「实时跟踪我跟它说过的股票」——这需要一个**状态机**，每只跟踪股在状态间迁移，状态变化才是提醒：

```
未覆盖 ──加入跟踪──▶ 观察中 ──────────────▶ 关注（估值进入区间+催化临近）
                      │  ▲                    │
                      ▼  │                    ▼
                   预警（风险事件/财报不符）   [买入区间] ──买入触发──▶ 持有
                      │                    │                     ▲
                      ▼                    ▼                     │
                   退出跟踪                卖出触发（目标价/止损/逻辑破坏）──┘
```

### 4.2 买卖点触发 = 三因子打分（避免噪音）

```
信号强度 = 0.4×催化强度 + 0.3×估值分位吸引力 + 0.3×技术位共振
触发条件：信号强度 > 阈值 AND 2hao 研究结论为「正面」 AND 3hao 回测验证通过
```

只有三者同时成立才提醒。任一不满足 → 只进日报不打扰。

## 五、下一步行动（按优先级）

1. **数据采集扩展**：akshare 拉公告/互动易/龙虎榜/资金流 → 落库（复用 `sync_qlib_data.py` 模式）

3. **每日简报模板**：晨间（隔夜信息+今日催化）+ 盘后（成交+资金流+异动归因）

### P1 — 两周内
4. **三因子触发引擎**：催化强度(新闻/公告 NLP) × 估值分位(financials.db) × 技术位(qlib) → 打分
5. **状态机迁移逻辑**：每只跟踪股按事件驱动状态变化，变化即提醒
6. **提醒通道**：桌面通知/邮箱（Claude 或 marvis 定时推送）

### P2 — 一个月内
7. **买卖点历史回溯验证**：把三因子触发在历史数据上跑一遍，看命中率（防提醒过拟合）
8. **定期交易方案**：周报（仓位调整建议）+ 月报（组合再平衡），复用 optimize_portfolio
