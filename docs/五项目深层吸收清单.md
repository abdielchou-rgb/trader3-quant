## 三、alphagen — 因子进化防退化（evolve 工厂增强）

| # | 可迁移模式 | 迁到3hao哪里 |
|---|-----------|-------------|
| 1 | **池化奖励+互相关拒绝**：适应度=新因子入池后的组合值；与池内任一因子 IC>0.99 即拒 | evolve 内维护容量~20 因子池，fitness 改读入池后组合值 |
| 2 | **每日截面 z-score + LCB 目标**：per-day 标准化，目标用 mean−β·std（下置信界）防单日过拟合 | compute_fitness 每日预归一，支持 LCB 目标切换 |
| 3 | **构建期合法性掩码**：逐 token 校验，滚动算符须 DeltaTime 栈顶、子树须含 featured 叶子 | gp.py 加 validate_next，init/变异拒非法子树 |
| 4 | **复杂度并入适应度**：>20 token 直接 -1（parsimony） | fitness 加节点数惩罚，进化期即压长树 |
| 5 | **重复表达式短路**：已评过直接返回缓存 | evolve 按 to_str 哈希去重，跳过重估 |
| 6 | **向量滚动+边界缓冲**：预垫边界，sliding_window_view 替代逐日 for | 6440 天规模提速关键 |
