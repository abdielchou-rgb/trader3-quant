# 3号交易员 v2.0 — 本机接入雪球/知乎/外网源（操作说明）

> 完成日期：2026-08-23
> 目标：在 Windows 本机跑通 雪球(自媒体) + 知乎(深度讨论) + 外网(路透/彭博/高盛) 三个源，接入 events.db 与三因子引擎。

---

## 一、为什么需要本机运行

沙箱（Claude VM）访问受限：
- **雪球**：被 WAF 拦（需要 cookie）
- **知乎**：API 401（需要认证 token）
- **外网**（路透/彭博/高盛/WSJ）：需代理或订阅

你的**本机**（可登录雪球/知乎、可配代理）可以绕过这些限制。

## 三、本机接入步骤（三步）

### 第 1 步：装依赖 + 配凭据

```bash
# 1. 依赖（在你本机的 Python 环境）
pip install requests akshare

# 2. 雪球 cookie（必需才能采雪球）
#    浏览器登录 xueqiu.com → F12 → Network → 点任意请求 → 复制"Cookie"请求头完整值
set XUEQIU_COOKIE=xq_a_token=xxxx;u=xxxx;...   # Windows CMD
# 或 PowerShell: $env:XUEQIU_COOKIE="xq_a_token=xxxx;..."

# 3.（可选）知乎 cookie
set ZHIHU_TOKEN=d_c0=xxxx;...

# 4.（可选，外网加速）如有能访问国际网的代理
set HTTPS_PROXY=http://127.0.0.1:7890
```

### 第 2 步：验证凭据

```bash
cd D:\Claude\projects\3号交易员
python scripts/run_local_sources.py --check-env
# 应显示 XUEQIU_COOKIE 已配置；未配置的先补第 1 步
```

### 第 3 步：采集

```bash
# 采全部三个源，三只自选股
python scripts/run_local_sources.py --codes 600519,000858,300750 --all

# 只采雪球
python scripts/run_local_sources.py --codes 600519 --xueqiu

# 全部自选股（默认 600519,000858,300750）
python scripts/run_local_sources.py --all

# 查看事件库状态
python scripts/run_local_sources.py --status
```

采集结果评分后写入 `data/events.db`（source = xueqiu / zhihu / global_news）。

## 五、三个源各自的实现细节

### 雪球（xueqiu）
- **需要**：`XUEQIU_COOKIE`（浏览器复制）
- **接口**：搜索讨论 `query/v1/search/status.json` → 若空则热帖热榜 `statuses/hot/listV2.json`
- **产出**：用户讨论标题/内容 → 催化评分（自媒体热度信号）

### 知乎（zhihu）
- **优先**：有 `ZHIHU_TOKEN` → 热榜 API `feed/topstory/hot-lists`
- **兜底**：无 token → DDG 搜索 `site:zhihu.com 关键词`（本机可过反爬）
- **产出**：高赞讨论标题 → 深度讨论信号（比雪球更有分析深度）

### 外网（global_news）
- **RSS 聚合**：路透 worldNews / WSJ 市场 / CNBC 财经 / MarketWatch（本机可直连）
- **兜底**：DDG 新闻搜索 `关键词 Reuters OR Bloomberg OR "Goldman Sachs"`
- **产出**：英文头条 → 外交消息信号（对齐华尔街/彭博/高盛视野）

## 六、常见问题

| 问题 | 处理 |
|------|------|
| 某源返回 0 条 | 先 `--check-env` 看 cookie 是否配了；雪球 WAF 严时多试几次或换 UA |
| 雪球 403 | cookie 过期——重新登录雪球复制 |
| 外网 RSS 连不上 | 本机没外网代理；设 `HTTPS_PROXY` 或仅用沙箱源 |
| collected=0 入库 | 事件已去重（同 code+source+title 只存一次），属正常 |

## 七、诚实边界

- 沙箱无法验证雪球/知乎/外网真实返回（被反爬/无代理）——**代码已按真实接口写、语法与导入已验证**，但真实返回需要你本机跑一次确认
- DDG 在沙箱确认触发 bot 验证（`search.py` 已自动检测并降级为 0 条）——本机通常可过
- 采集是"候选信号输入"，催化评分后仍需三因子 + 写作规范三道关才出口
