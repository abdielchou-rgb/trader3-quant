# AI 使用披露（AI Usage Disclosure）

## 声明

本项目在**测量构建**环节使用大语言模型（LLM）作为辅助工具，具体用途与范围如下：

| 用途 | 模型 | 人类监督 |
|---|---|---|
| 招股书品牌语言密度提取 | gpt-4o-mini (via LLM_MODEL env) | 全量输出人工抽检 + 双口径交叉验证 (M2) |
| 代码生成辅助 | Claude / GPT-4 (via IDE 集成) | 所有代码经 314+ 单元测试验证 |
| 文本预处理 | 无 LLM（纯正则/规则） | - |

## 关键保障措施

1. **双口径交叉验证**: BCI v1 (35-keyword density, 非 LLM) 与 M2 (IDF-weighted, LLM-assisted)
   相关系数 0.845，两者对 IPO 定价的结论方向一致
2. **事实性安慰剂检验**: LLM 提取的事实性声明（factual claims）不预测收益（p>0.05）
   ——排除了"LLM 幻觉驱动伪信号"的可能
3. **合成数据标注纪律**: 所有非真实数据均带"（合成数据）"标签，
   白名单模式自动禁用关键输入为合成值的估值方法
4. **模型版本记录**: `LLM_MODEL` 环境变量可冻结模型版本；提取脚本不含
   temperature 设置（API 默认），已列入待改进项

## 局限性

- LLM 提取不可完全复现（API 温度默认 > 0）；已交付全量原始输出
  (`llm_claims.csv`, 328KB) 供审计
- 无人工标注校准子集（kappa 未报告）——已列为投稿前 P0 补齐项
- 模型行为可能随 OpenAI 版本更新漂移——建议投稿时使用 API 快照或
  本地部署开源模型替代

## 政策依据

- AEA Data & Code Availability Policy (2023): 要求披露所有计算工具含 AI
- ICMJE/COPE 立场文件: AI 不得列为作者，但须声明使用范围
- 目标期刊（JCF/JBF/CER）2025 年起要求提交 AI 使用声明
