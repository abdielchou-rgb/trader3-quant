## 二、批次1：QUANTAXIS/backtrader 模式落地

### 1. QUANTAXIS 统一行情列访问器 — `trader3/v2/qa_accessor.py`

- 对齐 `QUANTAXIS/QADataStruct.py` 的列名语义，提供 `.open/.high/.low/.close/.volume/.amount/.prev_close` 属性壳
- 内置别名兼容（`close/c/收盘/close_price/last`，`volume/vol/成交量/volume_ratio` 等），底层 dict / DataFrame / 序列均可访问
- 字段缺失时兜底返回 `None`

### 2. 增量更新「查尾续拉」— `trader3/v2/sync_all.py`

- 对齐 `QUANTAXIS/QASU/save_tdx.py` 思想：先查本地已有数据最后日期（尾部），只拉取尾日期之后的增量，避免全量重拉
- 统一入口整合三类数据：
  1. `kline`：行情 K 线增量（akshare 日线 → `data/kline_cache/{code}.csv`，查尾续拉）
  2. `events`：事件/公告增量（复用 DataCollector，`collect_state.json` 查尾）
  3. `financials`：财务数据可达性检测（检测 financials.db；缺失时提示指向 2hao-analyst）
- 用法：`python -m trader3.v2.sync_all --mode all|kline|events`

### 3. backtrader 可插拔费用模型 — `trader3/v2/costs.py`

- 对齐 backtrader `CommissionInfo` 设计：佣金/印花税/冲击成本集中为参数对象
- 默认值对齐原 `backtest.py` 固定费率：`stamp_tax_bp=10 / commission_bp=2 / slippage_bp=5` → `TOTAL_COST_BP=17bp`
- 提供 `total_bp()`（单笔双边总成本）与 `turnover_cost(turnover)`（按换手率扣减组合日收益）

### 4. backtrader 涨跌停成交量限制 Filler — `trader3/v2/fillers.py`

- 对齐 backtrader `Fillers` 思想：成交受「当根 Bar 流动性」约束，避免涨停一字板（无卖盘）买入、跌停一字板（无买盘）卖出时假设全额成交
- `FixedSizeFiller`：固定按请求量成交（默认，向后兼容）
- `BarVolumeFiller`：按当根 Bar 成交量/涨跌停状态限制实际成交量
  - 涨停（price >= prev_close*(1+limit)）：买入量 ≤ 可卖供给（通常为 0 / 少量）
  - 跌停（price <= prev_close*(1-limit)）：卖出量 ≤ 可买承接（通常为 0 / 少量）
  - 未触及涨跌停：按 `bar.volume` 的 `capacity_ratio`（如 10%）限制

### 5. T+1 三态校验

- `trader3/v2/execution_realism.py` 已落地 T+1 三态撮合 + 涨跌停拦截（his/today/frozen），与 QUANTAXIS 的 `his/today/frozen` 语义一致，无需改动
