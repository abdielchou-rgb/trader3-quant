## 二、最大启发：授人以渔的「DDM + 预期差」是你买卖点触发引擎的理论内核

### 2.1 核心思想（直接可用）

广发戴康的核心：策略的本质是 **DDM 贴现模型**，核心理论是 **预期差**。

```
股价 = 预期现金流的贴现
买入点 = 市场定价 < 你的 DDM 估值（预期差为正）的那一天
卖出点 = 预期差收敛/反转的那一天
```

**这就是你的「三因子买卖点触发」的理论升级版**。当前方案（催化×估值×技术）缺一个"锚"——DDM预期差恰好补上：

| 原三因子 | 升级为（套用 DDM 预期差） |
|----------|--------------------------|
| 催化强度 | 什么事件会改变市场对未来现金流的预期？（盈利上修/行业景气/政策） |
| 估值分位 | 当前价格对应的隐含预期 vs 中枢合理预期（预期差大小） |
| 技术位共振 | 价格在预期差被市场确认时的动量确认（DMA确认） |

### 2.2 直接可落地的子框架

- **大势研判（因子与驱动）**：不同宏观因子周期 → 选最优驱动要素 → 可做成 market regime 的第二层输入（除HMM外，加宏观因子切换）
- **底部框架（三大维度二十指标）**：历史底部识别 → 可直接移植为「买入时机」过滤器（仅在非底部区域允许触发）→ 或做成「市场风险状态」评分
- **行业比较（景气与预期）**：基于"动态景气预期"做行业轮动 → 对应「每日行业景气扫描」，输出今日哪些行业景气上修
- **盈利周期（三个中周期**：偿债/产能/库存**+杜邦+现金流）**：A股盈利位置 → 对应「个股盈利周期定位」，判断个股处于盈利周期哪个阶段

## 三、宏观方法论 → 每日数据采集的「配方清单」

### 3.1 高频观测体系（信达）—— 你的每日采集能做什么

这套方法论告诉你：**用哪些高频指标可以提前/同时判断宏观与行业景气**。直接变成采集清单：

| 高频指标 | 映射到 | 采集来源 | 频率 |
|----------|--------|----------|------|
| 粗钢产量/高炉开工率 | 钢铁行业景气 → 钢价/上下游 | akshare/行业数据 | 日 |
| 江浙织机PTA负荷率 | 纺织化纤景气 | 行业网站(可选) | 周 |
| 半钢胎开工率 | 汽车/轮胎景气 | 行业网站(可选) | 周 |
| 30城地产成交 | 地产景气 → 上下游链 | akshare | 日 |
| 乘用车销量(乘联会) | 汽车消费景气 | akshare | 日 |
| 电影票房 | 消费/传媒景气 | akshare | 日 |
| 螺纹钢/水泥价格 | 基建/建材景气 | akshare | 日 |

**做法**：不做全量宏观建模，只做「你关注的行业」的高频景气快照，作为行业研究的每日温度计。

### 3.2 宏观方法论的实操结论

- 高频指数与月度官方数据（工业增加值/社零/固定投资）相关性高 → 你的**每日简报**可加一栏「今日高频景气」：用这些高频指标的趋势/同比，提示今日宏观温度
- 测算模型（制造业/基建/地产投资）可作为 **2hao 宏观框架的公式库**，不必每期手算

## 四、产业生命周期 → 行业研究的骨架

### 4.1 生命周期五阶段（决定策略态度）

```
导入期 → 成长期 → 成熟期 → （出清期）→ 衰退期
```

每个阶段的投资含义不同（导入期看渗透率/成长期看景气/成熟期看格局/出清期看出清完成度）。**这比"景气度"单维度更能指导行业研究该看什么**。

### 4.2 出清四种模式（个股/行业筛选的高级过滤器）

| 出清模式 | 特征 | 投资含义 |
|----------|------|----------|
| 严格型出清 | 彻底出清（白酒/工程机械/水泥） | 格局好，龙头溢价 |
| 成长型出清 | 需求扩张中出清（家电） | 量价齐升期 |
| 激进型出清 | 逆势资本开支（养殖） | 周期反转弹性大但风险高 |
| 普通型出清 | 缓慢出清 | 谨慎 |

**直接可用于**：你的自选股**买入前检查**——如果个股所属行业处于「激进型出清」且公司在逆势加杠杆，触发风险预警。这是 ai-berkshire"护城河"之外的第二个行业格局维度。
